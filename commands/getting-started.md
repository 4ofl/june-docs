# Getting Started & Access Guide

June is an invite-only, security-hardened Discord utility and intelligence platform. Because June provides powerful diagnostics, forensic tools, and private mail services, access is strictly governed by an administrative authorization whitelist.

---

## 1. Access Model & Whitelisting

Unlike public utility bots that can be added by anyone, June operates on an **authorized whitelist**:

1. **Whitelisted Users**: Individual Discord accounts added by the bot operator can execute June's complete suite of utility, intelligence, and privacy commands in direct messages (DMs) or within any server where user apps are enabled.
2. **Authorized Servers**: Servers invited through server-locked installation links issued by the bot operator.
3. **Public Discord Users**: Non-whitelisted users on an authorized server have access only to a constrained set of safe general utilities (e.g. timestamp parsing, basic unit conversions).

### How to Request Access
To be added to the June whitelist, you must contact the bot operator directly:
- **Dashboard Request**: Authenticate with Discord at [june.4ofl.dev/dashboard](https://june.4ofl.dev/dashboard). If your account is not yet whitelisted, you can submit an access request directly to the operator.
- **Direct Operator Contact**: Reach out to `4ofl` or email `aby@4ofl.dev` with your Discord User ID.

## 2. Installation Modes

June supports Discord's modern **dual-installation architecture**:

### Mode A: User App Installation (Recommended)
You can install June directly to your personal Discord account:
- **Where It Works**: Works in **any Discord channel, group DM, or direct message**, even on servers where June is not officially installed.
- **Permissions**: June runs as your personal app context. Responses can be made private (ephemeral) or visible to the channel.
- **Installation**: Once whitelisted, click June's profile in Discord and choose **"Add App"** or navigate to [june.4ofl.dev/add/user](https://june.4ofl.dev/add/user).

### Mode B: Server / Guild Installation
Guild installations allow all authorized server members to interact with June:
- **Invitation-Only**: Server installations require a server-locked OAuth2 link generated by the operator (`/add/server?guild=<guild_id>`).
- **Required Discord Permissions**: `View Channels` and `Send Messages` (`permissions=3072`). June responds using interaction webhooks and does not require administrative or message-reading permissions.

## 3. First Steps: Personalizing Your Settings

After gaining access to June, configure your default preferences using `/settings`:

### 1. Set Your Timezone
Setting your timezone allows commands like `/time` and `/remind` to interpret natural language dates and timestamps in your local time:
```text
/settings timezone value:America/New_York
```
*(Supports autocomplete for all standard IANA timezones).*

### 2. Set Default Response Visibility
Choose whether command replies should be ephemeral (hidden to everyone except you) by default:
```text
/settings ephemeral value:True
```

### 3. Configure Clock & Measurement Units
```text
/settings clock value:24-hour
/settings units value:Metric
```

### 4. Review Your Stored Settings
Check your configured preferences at any time:
```text
/settings view
```

## 4. Self-Service Data Rights & Privacy

June provides complete GDPR-compliant self-service tools directly in Discord:

### Inspect Stored Records
Check the total number of receipts, reminders, tempmail leases, and watch targets stored under your account:
```text
/data view
```

### Export Your Data (Data Portability)
Download a complete, machine-readable JSON archive of all your personal records:
```text
/data export
```

### Permanent Erasure ("Right to be Forgotten")
Permanently purge all receipts, scheduled reminders, user preferences, temporary inbox leases, watch targets, managed paste records, and command history associated with your Discord User ID:
```text
/data delete
```
*(Data deletion executes immediately inside an atomic SQLite transaction and invalidates all memory caches without operator intervention).*
