## `/dict`

> Look up an English word.

| Attribute | Details |
| :--- | :--- |
| **Access Tier** | All Users |
| **Provider** | Free Dictionary API |
| **Data Stored** | Ephemeral |

### Options

| Option | Description | Type | Required |
| :--- | :--- | :--- | :--- |
| `word` | Word to define. | String | Yes |
| `ephemeral` | Hide this response. | Boolean | No |

### Examples

```text
/dict word:"ephemeral"
```
