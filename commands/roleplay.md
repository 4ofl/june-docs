# Roleplay Actions

Interactive social and roleplay actions with custom Discord embeds and Components V2.

> [!NOTE]
> Roleplay commands are consolidated into a single structured command (`/roleplay`) with rich Discord Components V2 and customizable recipient targets.

---

## `/roleplay`

> Use a roleplay action.

| Attribute | Details |
| :--- | :--- |
| **Access Tier** | All Users |
| **Provider** | Local Component Builder & Nekos API |
| **Data Stored** | Ephemeral |

### Subcommands
